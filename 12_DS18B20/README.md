# DS18B20 Waterproof

## Library

- Nama: `OneWire`
- Sumber: https://github.com/PaulStoffregen/OneWire
- Nama: `DallasTemperature`
- Sumber: https://github.com/milesburton/Arduino-Temperature-Control-Library

Pasang keduanya melalui Arduino IDE **Library Manager**.

## Koneksi dasar

- Merah: 5V
- Hitam: GND
- Kuning/data: D2
- Tambahkan resistor 4.7K ohm antara DATA dan 5V.
