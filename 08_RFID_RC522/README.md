# RFID RC522

## Library

- Nama: `MFRC522`
- Arduino IDE: **Library Manager** -> cari `MFRC522` -> install
- Sumber: https://github.com/miguelbalboa/rfid

## Koneksi Arduino Uno

| RC522 | Arduino Uno |
|---|---|
| 3.3V | 3.3V, jangan 5V |
| GND | GND |
| SDA/SS | D10 |
| SCK | D13 |
| MOSI | D11 |
| MISO | D12 |
| RST | D9 |
