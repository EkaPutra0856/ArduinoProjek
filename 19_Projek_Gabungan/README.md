# Projek Gabungan Sederhana

Semua sketch di sini menggabungkan dua atau tiga alat. Buka setiap sketch dari subfoldernya masing-masing.

## Daftar proyek

1. Servo + ultrasonic: servo membuka saat benda lebih dekat dari 15 cm.
2. Servo + ultrasonic + LCD: jarak ditampilkan di LCD dan servo bergerak otomatis.
3. Soil moisture + LCD: nilai kelembapan tanah ditampilkan di LCD.
4. Ultrasonic + buzzer: alarm berbunyi jika benda terlalu dekat.
5. LDR + LED: lampu menyala saat gelap.
6. DHT11 + LCD: suhu dan kelembapan tampil di LCD.
7. Rain sensor + servo + buzzer: servo bergerak dan alarm berbunyi saat hujan.
8. Flame sensor + buzzer + LCD: alarm api dengan informasi di LCD.
9. MQ-2 + buzzer + LED: indikator asap atau gas.
10. Sound sensor + relay: suara mengaktifkan relay.
11. SW-420 + buzzer + LED: alarm getaran.
12. RFID + servo + buzzer: kunci servo dengan kartu RFID.
13. DS18B20 + LCD: suhu tampil di LCD.

Library yang dibutuhkan hanya untuk proyek LCD: `LiquidCrystal I2C`.
